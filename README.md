# MHD Library

کتابخانه شخصی مهدی — یک آرشیو تحت وب برای مرور، جست‌وجو و ثبت کتاب‌ها.

## امکانات
- ۵۷۲ قلم ثبت‌شده در نسخه فعلی
- جست‌وجو و فیلتر کتاب‌ها
- شماره ثبت یکتا
- اطلاعات کتابشناختی و محل فیزیکی
- وضعیت مطالعه و امتیازدهی
- نمایش سازگار با موبایل
- حالت روشن و تاریک
- خروجی JSON و CSV
- لینک جست‌وجوی هر کتاب در ایران‌کتاب
